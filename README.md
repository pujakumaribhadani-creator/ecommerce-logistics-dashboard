# 📦 E-commerce Logistics Dashboard

An interactive **E-commerce Logistics Analytics Dashboard** built with Python, Pandas, Plotly, and Streamlit to analyze sales performance, delivery efficiency, warehouse operations, customer experience, and fraud trends.

## 🚀 Live Dashboard

🔗 **Streamlit App:** [[Add your Live Streamlit Link]](https://ecommerce-logistics-dashboard-hyl8abwuvyfebtpxaqhsed.streamlit.app/)

---

## 📌 Project Overview

This project analyzes **25,000 e-commerce logistics records** and converts raw operational data into meaningful business insights through an interactive dashboard.

The dashboard allows users to explore logistics performance using dynamic filters and visualizations.

### 🎯 Key Objectives

* Monitor overall sales and order performance
* Analyze delivery efficiency and delays
* Compare warehouse performance
* Understand the impact of weather on delivery
* Analyze product returns
* Monitor fraud cases
* Understand customer review patterns

---

## 📊 Key Performance Indicators

The dashboard tracks the following KPIs:

| KPI                    | Description                            |
| ---------------------- | -------------------------------------- |
| 📦 Total Orders        | Total number of orders                 |
| 💰 Total Revenue       | Overall revenue generated              |
| 💵 Average Order Value | Average value per order                |
| 🚚 On-Time Delivery    | Percentage of orders delivered on time |
| ⏳ Average Delay        | Average delivery delay in days         |
| ⭐ Average Rating       | Average customer review score          |
| 🔄 Return Rate         | Percentage of returned orders          |
| 🚨 Fraud Rate          | Percentage of flagged orders           |

## 🔍 Interactive Filters

## ▶️ How to Run Locally

### 1. Clone the repository

```bash
git clone [Add your GitHub Repository Link]
```

### 2. Navigate to the project folder

```bash
cd ecommerce-logistics-dashboard
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Streamlit application

```bash
streamlit run app.py
```

The dashboard will open in your browser.
