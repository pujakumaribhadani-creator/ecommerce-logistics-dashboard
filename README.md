# 📦 E-commerce Logistics Dashboard

## 📌 Project Overview
An interactive logistics analytics dashboard built using Python, Streamlit, Pandas, and Plotly to monitor sales, delivery performance, warehouse efficiency, customer returns, and fraud trends.

## 🎯 Key Features
- Interactive Filters
- KPI Cards
- Revenue Analysis
- Delivery Performance Analysis
- Warehouse Analysis
- Fraud Analysis
- Download Filtered Data

## 🛠️ Tech Stack
- Python
- Pandas
- Plotly
- Streamlit

## 📊 Dataset
25,000 E-commerce Logistics Records

## 🚀 How to Run

```bash
streamlit run app.py
```
